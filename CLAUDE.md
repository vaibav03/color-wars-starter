# Color Wars starter kit

Only `strategy.py` is edited. See `BRIEF.md` for the rules.

## Verification commands

Each must end with `RESULT win` and print no line starting with `KIT-ERROR` or `KIT-WARN`.

- `python3 simulate.py --side red --opponent sample`
- `python3 simulate.py --side red --opponent random`
- `python3 simulate.py --side red --opponent house`
- `python3 simulate.py --side blue --opponent sample`
- `python3 simulate.py --side blue --opponent random`
- `python3 simulate.py --side blue --opponent house`
